# Help and Usage Guide: system

## Quick Start
```powershell
# Execute system.ps1 with verbose output:
..\system.ps1 -Verbose
```

## Parameters & Options
- -DryRun: Previews actions without filesystem or system modifications.
- -Verbose: Displays detailed progress indicators and diagnostic logs.

## Troubleshooting
- Verify required execution policies (-ExecutionPolicy Bypass).
- Check target logs in logs/SortLog.md or system event viewers.
